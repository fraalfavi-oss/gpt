# Archivo de conversaciones GPT

Repositorio para respaldos opcionales de conversaciones y archivos asociados.

**Privacidad:** antes de archivar conversaciones personales, configurar este repositorio como privado. No borrar conversaciones originales hasta comprobar la integridad de la exportacion y los adjuntos.

Estructura prevista: `conversaciones/AAAA-MM-DD-tema/`, con transcripcion, adjuntos, generados e inventario.
